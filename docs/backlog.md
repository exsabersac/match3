# 新玩法待办清单（对照开心消消乐）

2026-09-30 解除机制冻结后的新玩法清单。先盘点现有内容，再列出开心消消乐里有、本项目还没有的玩法，按「可玩性收益 / 工作量」排序。每个玩法单独一个提交：带测试、中文文档、至少一关（或每日挑战）用上它、前端能看出来。

## 1. 现有内容盘点（2026-09-30，重构 11 刀之后）

**宝石与特效**：5 色宝石；直线（横 / 竖）、炸弹、彩虹（魔力鸟）。形状表只有「五连 → 彩虹」「四连 → 直线」两条，**L / T 形不出炸弹**，炸弹只能靠关卡放置、彩蛋、果汁机得到。组合表：直线 × 直线十字、直线 × 炸弹三行三列、炸弹 × 炸弹 5×5、彩虹 × 彩虹清全盘；彩虹 × 直线 / 炸弹只清同色（不会把同色变成特效）。

**格子上的元素（共 31 个内置条目）**

| 类别 | 元素 |
|---|---|
| 地面 / 修饰 | 冰层（修饰）、果冻（地面层，双层） |
| 叠层（8 种） | 草、藤蔓、巧克力、迷雾、锁链、冰冻、窗帘、蒸汽 |
| 障碍 / 收集 | 石头、宝箱、蜂蜜、气球、饼干（金豆荚式，底边收集）、蛋糕、魔法帽、果汁机、蜗牛、保险箱、双面块、彩蛋、染色瓶、时间精灵（+2 步）、倒计时炸弹、气泡 |

**关卡级元素**：飞碟、皮带、传送门、地毯（另有核心地面层 ground）。

**其他**：锤子 / 自由交换 / 十字三种道具；每日挑战 10 种目标轮换；40 关（下标 0–39，最后两关 38 果冻、39 气泡）。

**扩展点（新玩法优先落在这里，尽量不碰主流程）**：`Caps` 能力记录（onAdjacent / onDirect / atEnd / blocksSwap / falls…）、`CellTable` 条目、`Custom` 本体 + `CustomState`、关卡级元素（`LevelElement` + 开放消息 `Message`）、规则表（形状表 `ShapeRule`、组合表、步末表、补充策略）、前端 `Presentation` 表 / `Match3.View` 视图模型、`Level` 记录字段（`lvlPlacements`、`lvlRules` 等）。

## 2. 待办清单（按收益 / 工作量排序）

图例：**独立** = 和其他项几乎没有文件重叠，可以另开一条线并行；**冲突 #n** = 和第 n 项会改同一批文件，宜串行。所有项都会在 `src/Match3/Levels/Campaign.hs` 末尾追加关卡、在测试里改「关卡总数」、重录金标准末尾一段——这几处按「预留关卡下标、合并后重录快照」处理，不算冲突。

### 1. L / T 形 → 炸弹（P0）
- **原作规则**：同色 5 颗组成 L 形或 T 形（横竖两条三连在一格相交）时，交点生成一颗爆炸特效（区域炸弹）。
- **工程简化**：横竖两条同色连线相交即算 L / T，炸弹放在交点；五连仍然优先出彩虹；带四连的 L / T 出炸弹不出直线。作为**关卡规则开关** `bomb_shapes`（`Level.lvlRules`）只在新关打开——全局打开会改变原有 40 关的行为，需要 yu 另外批准。
- **扩展点**：形状表 `ShapeRule` 新增一条规则；关卡级元素 `BombShapes` 回复新消息 `Shaping`，在走棋前替换注册表的形状表。
- **预计碰的文件**：`Element/Builtin/Gem.hs`、`Element/Builtin/Level.hs`、`Element/Builtin.hs`、`Element/Message.hs`、`Element/Level.hs`、`Game/Resolve.hs`（一行）、`Game/State.hs`、`Levels/Level.hs`、`Levels/Campaign.hs`。
- **独立性**：基础项。#5、#8 依赖它的规则开关；和 #4、#6 同改 `Builtin/Level.hs`。

### 2. 魔法石（P1，独立）
- **原作规则**：固定在格子上不动；旁边每发生一次消除就充能一格，充满后在回合末向十字方向发射，清除整行整列。
- **工程简化**：`Custom "magic_stone"`，`CustomState` 记充能 0–3；邻格消除 +1（`onAdjacent`），满 3 后步末（`atEnd`）清除所在行和列并归零；挡交换、不下落、不可被消除。
- **扩展点**：`Caps`（onAdjacent + atEnd）、`CellTable` 条目、`Presentation` 画充能格数。
- **预计碰的文件**：`Element/Builtin/Obstacle.hs`（追加一个元素）、`Element/Builtin.hs`（注册一行）、前端贴图（`app/UI/BoardArt.hs` / 图集）、`Levels/Campaign.hs`。
- **独立性**：**独立**，适合并行。

### 3. 毛球（P1，独立）
- **原作规则**：毛球占一格，挡交换、会随重力下落；旁边消除就被消灭（计入目标）；每回合末没被消灭的毛球跳到相邻的普通宝石格。
- **工程简化**：`Custom "furball"`，邻消即灭、随重力下落；步末随机跳到相邻普通宝石格（随机数只在有毛球的关卡消耗，保证原有关卡的随机序列不变）。
- **扩展点**：`Caps`（blocksSwap + falls + onAdjacent + atEnd）、步末表一行、`Presentation`。
- **预计碰的文件**：`Element/Builtin/Actor.hs`（追加一个元素）、`Element/Builtin.hs`、`app/UI/BoardArt.hs`、`Levels/Campaign.hs`。
- **独立性**：**独立**，适合并行（需在测试里确认原有关卡随机序列不变）。

### 4. 雪怪 Boss（P1，冲突 #1 / #6）
- **原作规则**：棋盘上方有一个 Boss 带血条，每次消除按消除数量扣血；打死 Boss 过关，Boss 每几回合会往棋盘上丢障碍。
- **工程简化**：关卡级元素 `Boss`，HP 按每步清除格数扣减；目标用 `CountNamed "boss"`；丢障碍暂不做（第二步再加）；HUD 血条经 `Match3.View` 输出，前端画一条进度条。
- **扩展点**：关卡级元素 + 消息、`Match3.View`、`Presentation`。
- **预计碰的文件**：`Element/Builtin/Level.hs`、`Element/Builtin.hs`、`Element/Level.hs`、`Match3/View.hs`、`app/UI/HudBlocks.hs`、`Levels/Level.hs`、`Levels/Campaign.hs`。
- **独立性**：和 #1 / #6 同改 `Builtin/Level.hs`、`Element/Level.hs`，宜串行。

### 5. 魔力鸟组合增强（P1，依赖 #1）
- **原作规则**：魔力鸟 + 直线 → 棋盘上所有同色宝石变成直线特效并依次引爆；魔力鸟 + 炸弹 → 同色全变炸弹再引爆。
- **工程简化**：按规则开关 `rainbow_combo` 打开；组合表新增两条：同色全部标记为对应特效后引爆一轮（不做逐个动画，只用现有波次展示）。
- **扩展点**：组合表 + 关卡规则开关（复用 #1 的 `lvlRules` / 消息机制）。
- **预计碰的文件**：`Element/Builtin/Gem.hs`（组合规则）、`Element/Builtin/Level.hs`、`Element/Message.hs`、`Levels/Campaign.hs`。
- **独立性**：依赖 #1 的开关机制；和 #1 同改 `Gem.hs`，#1 合入后可做。

### 6. 掉落口 / 饼干生成口（P2，工作量小，冲突 #1 / #4）
- **原作规则**：指定列顶端是金豆荚掉落口，按一定节奏掉下金豆荚，收集到底部算目标。
- **工程简化**：关卡级元素 `Dropper`，在补充阶段（回复 `Refilling` 消息）按「场上饼干少于 N 个」在指定列顶放一个饼干；复用已有饼干的底边收集。
- **扩展点**：关卡级元素 + 补充策略消息。
- **预计碰的文件**：`Element/Builtin/Level.hs`、`Element/Builtin.hs`、`Levels/Level.hs`、`Levels/Campaign.hs`、前端画掉落口标记。
- **独立性**：和 #1 / #4 同改 `Builtin/Level.hs`。

### 7. 变色龙（P2，独立）
- **原作规则**：变色宝石每回合结束换一种颜色，玩家要抓住时机凑色。
- **工程简化**：修饰层 / `Custom` 宝石，步末按固定顺序循环换色（不耗随机数），可参与消除。
- **扩展点**：`Caps`（atEnd + 可匹配）、步末表、`Presentation` 画彩色描边。
- **预计碰的文件**：`Element/Builtin/Collectible.hs` 或新模块、`Element/Builtin.hs`、`app/UI/BoardArt.hs`、`Levels/Campaign.hs`。
- **独立性**：**独立**。

### 8. 过关剩余步数奖励（P2，依赖 #1）
- **原作规则**：「Bonus Time」：过关后剩余步数逐一变成随机特效并引爆，额外加分。
- **工程简化**：规则开关 `bonus_time`；过关时剩余每步在随机普通宝石上放直线特效，统一引爆一轮计分；只加分，不改胜负。
- **扩展点**：终盘表（步末表的终盘段）+ 规则开关。
- **预计碰的文件**：`Game/EndPhase.hs`（终盘段）、`Element/Builtin/Level.hs`、`Levels/Campaign.hs`、前端结算动画。
- **独立性**：依赖 #1 的开关；与 #1 / #4 / #6 同改 `Builtin/Level.hs`。

### 9. 魔法地格（P2，独立）
- **原作规则**：地面上的魔法格，特效在上面引爆时范围加大。
- **工程简化**：地面层新种类 `magic`；该格的特效引爆时额外清除一圈。
- **扩展点**：地面层（ground）+ 特效展开。
- **预计碰的文件**：`Element/Builtin/Ground.hs`、前端地面贴图、`Levels/Campaign.hs`。
- **独立性**：**独立**（和果冻共用地面层实现，但只追加分支）。

### 10. 流沙（P2）
- **原作规则**：流沙格每回合把其中的宝石往下「吞」一格，影响落点。
- **工程简化**：叠层新种类，步末把该格内容和下方格交换（遇障碍停止）。
- **扩展点**：叠层 + 步末表。
- **预计碰的文件**：`Element/Builtin/Layer.hs`、`Element/Builtin.hs`、前端。
- **独立性**：基本独立，但步末顺序要和蒸汽 / 蜗牛协调。

### 11. 海洋生物（冰下多格，P2，工作量大）
- **原作规则**：冰层下藏着 2×1 / 2×2 的生物，全部覆盖冰都打碎后救出。
- **工程简化**：关卡级元素记录生物矩形，冰层全清即计数。
- **扩展点**：关卡级元素 + 目标计数 + 前端多格贴图。
- **独立性**：和 #4 同改关卡级元素文件。

### 12. 之后（P3）
- **栏杆 / 墙**：格子之间的挡板，阻止交换和匹配——要改连线查找与下落主流程，最后再做。
