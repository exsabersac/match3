# 键位与操作（网页版，唯一前端）

网页（`web/www/`）是本项目唯一的前端：浏览器直接玩，安卓是网页套壳（[android.md](android.md)），PC 端以后同样给网页套壳。原 SDL2 桌面版（`match3-sdl`）已于 `refactor/web-only` 移除，它的交互在移除前已全部迁到网页（[web.md §2.6](web.md#26-桌面版功能迁移featweb-sdl-parity)）。

前端：`web/www/main.js`（指针事件 `pointerdown` / `pointerup` 点选与拖划、`keydown` 按键表、常驻按钮与菜单的 `onButton`）。规则一律在 Haskell 核心里经通用接口 `gameStep`（`Match3Web.Api` → `Match3.Engine.match3Shell`；撤销历史在 `Engine.History`），JS 不做任何规则判断。点选与拖动松手的判定（两步点选、松手格与起点相邻才交换）在 JS 里做，同原桌面版（原通用网格组件 `Engine.GridUI` 已于 `refactor/web-only-2` 删除）。

## 基本操作

| 输入 | 行为 |
|------|------|
| 点两格（相邻） | 交换（核心 `m3Swap`） |
| 拖划到相邻格 | 同上；拖过半格即交换（鼠标或触摸） |
| 无三连 / 挡交换 | 弹回原位；提示清空；不播连击特效，也不重播上一步的回放 |
| 回放中点棋盘 / 空格 / 回车 / `N` | 加速回放（阶段机每帧推进 3 帧，约 3 倍），连锁各轮和步末各段仍逐个可见；只作用于逐轮回放，洗牌后的轻落不加速 |

## 常驻按钮与菜单

常驻按钮只有 **撤销 / 提示 / 菜单** 三个（保住格子大小与 ≥ 44 CSS px 触控）；其余入口都在菜单面板里。菜单打开时冻结回放；点空白处、`Esc` 或「继续游戏」关闭；菜单开着时按任一快捷键先关菜单再执行。

| 按键 | 触屏入口 | 说明 |
|------|----------|------|
| `H` | 「提示」（常驻） | 高亮一手；无步时提示「菜单 → 洗牌」 |
| `U` / `Z` | 「撤销」（常驻） | 撤销一步（核心 `Engine.History`，最多 20 步；终局后仍可撤销） |
| `1` / `2` / `3` | 菜单「锤子 / 自由交换 / 十字消」（显示剩余次数） | 进入道具点选模式，见下节 |
| `S` | 菜单「洗牌」 | 手动洗牌（终局后无效） |
| `D` | 菜单「每日挑战」 | 本地今天的每日挑战（`?daily=YYYY-MM-DD` 可指定日期） |
| `M` | 菜单「选关地图」 | 点已解锁关跳关；点当前关 / 未解锁 / 空白关闭 |
| `R` | 菜单「重开本关」 | 每日挑战按开局步数与原目标换种子重开；暂停中也可 |
| `N` / 空格 / 回车 | 点棋盘 | 回放中加速；结局后前进（过关带入剩余步数，最多 3 步；失败重开）；过关时「›」也是前进 |
| `P` | 菜单「按键说明」 | 暂停 + 完整按键说明（冻结动画，清掉拖划 / 选中）；点任意处继续 |
| `K` / `B` | 菜单「音效 / 音乐」 | 开关音效 / BGM，偏好存 localStorage；HUD「效 / 乐」芯片只显示状态 |
| `?` | 菜单「本关说明」 | 本关特殊格子说明 |
| — | 菜单「上一关 / 下一关」 | 自由切关 |
| `Esc` | — | 关最上层浮层（菜单 → 暂停 → 地图 → 说明 → 道具模式）；退出归浏览器 / PC 壳 |

带 Ctrl / ⌘ / Alt 的组合键一律不拦，留给浏览器和 PC 壳。

## 播放锁定

交换补间、逐轮回放（含步末段）和洗牌轻落播放期间：

| 输入 | 播放中 |
|------|--------|
| 点格 / 拖划 | **锁定**：不选格、不交换；点棋盘＝加速 |
| `1` / `2` / `3` 道具、`U` 撤销、`S` 洗牌 | **锁定** |
| `H` 提示、`D` 每日、‹ › 切关 | **锁定** |
| `N` / 空格 / 回车 | 加速（不会推进到下一关 / 重试） |
| `M` 地图、`P` 暂停、`R` 重开、`K` / `B` | 可用（暂停 / 地图冻结动画，关闭后继续播） |

过关 / 胜利 / 失败面板在回放播完后才画出，最后几轮不会被面板挡住；面板出现后点棋盘或 `N` / 空格 / 回车才推进。回放的时间线、等级样式与步末阶段见 [`ui-art.md` 连击表现](ui-art.md#连击表现逐轮回放)。

## 道具模式

| 键 | 模式 | 行为 |
|----|------|------|
| `1` | 锤子 | 再点一格 → 锤掉；再按 `1` 取消；没有次数时提示 |
| `2` | 自由交换 | 点两格（可不相邻）→ 交换；再按 `2` 取消；0 次不进模式；换不掉时留在模式（`keepTool`，规则 `UI.MoveText.keepsTool`） |
| `3` | 十字消 | 再点一格 → 清该行与该列；再按 `3` 取消 |
| 先选中格再 `1` / `3` | — | 对该格立即锤 / 十字（有次数时） |

锤子对果汁机 / 蜗牛 / 染色瓶 / 魔法帽 / 饼干免疫：不扣次数（规则层 `hitImmuneWith`）。点选模式下棋盘上沿有横幅提示当前道具。

## HUD 提示

- 有键盘鼠标的设备上，开局 / 取消暂停后棋盘底部短暂显示按键条。
- 第 1 关开局自动亮提示，横幅「按 H 查看提示」。
- 暂停页列出全部按键（第三列是触屏入口）；结局面板提示继续方式（回放播完才出现）。
- 连锁回放中右下角分数芯片显示当前轮「连击 xN」（第 1 轮显示滚动上涨的分数），全部播完后若最高连击 ≥ 2 显示「N 连击！」。
- 窗口标题（`document.title`）= `Match3.View.titleLine` + 最近提示；PC 壳一般把它显示在标题栏。

弹字 / 浮字 / 连击徽章的颜色、各动画的帧数读表现表 `UI.Presentation`（经 `m3Meta` 下发，见 [ui-art.md「表现表」](ui-art.md#表现表第-10-刀)）；音效由 `web/www/audio.js` 按独立的音效与 BGM 开关播放。

更完整的功能与关卡表见根 [`README.md`](../README.md)，网页版的构建、部署与测试见 [web.md](web.md)。
